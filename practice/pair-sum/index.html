Pair Sum

Interview clock25:00

Given a list of integers `nums` and an integer `target`, return the indices of the two numbers that add up to `target`. Each input has exactly one solution, and you may not use the same element twice. Return the indices in any order.

Examples

  • Input

    nums = [2, 7, 11, 15], target = 9

    Output

    [0, 1]

    2 + 7 = 9.

  • Input

    nums = [3, 2, 4], target = 6

    Output

    [1, 2]

Constraints

  • 2 ≤ n ≤ 10^4
  • -10^9 ≤ nums[i], target ≤ 10^9
  • Exactly one valid pair.
